# Results

- [Eight-configuration ablation](ablation_latest/README.md): [Chinese HTML](ablation_latest/report_zh.html) / [English HTML](ablation_latest/report_en.html).
- [Training validation](reranker_training_100/README.md): product-group cross-validation, model selection and out-of-fold scores.

The ablation directory is the single source for all eight Top100 runs, aggregate metrics, per-query metrics, paired comparisons and subgroup results. Candidate text is stored in the evaluation corpus; only retrieval features and semantic caches are stored with the runs. Source hashes identify the code in Git instead of duplicating source trees.

See the [evaluation guide](../evaluation/README.md) for the two maintained datasets and commands.
